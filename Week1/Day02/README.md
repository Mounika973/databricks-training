# Employee SQL Practice Queries

This repository contains SQL practice queries created using an **Employees** database. The queries are designed to practice different SQL concepts such as data retrieval, filtering, grouping, sorting, aggregate functions, logical operators, and pattern matching.

The database includes employee-related information such as employee ID, employee name, department, salary, city, and experience. By working on these queries, I practiced writing SQL statements for real-world employee management scenarios.

## Topics Covered

* Basic `SELECT` queries
* Filtering data using `WHERE`
* Aggregate functions:

  * `SUM()`
  * `AVG()`
  * `COUNT()`
  * `MIN()`
  * `MAX()`
* Grouping data using `GROUP BY`
* Filtering grouped data using `HAVING`
* Sorting records using `ORDER BY`
* Using `DISTINCT`
* Comparison operators
* Logical operators:

  * `AND`
  * `OR`
  * `NOT`
* `IN` and `NOT IN`
* `BETWEEN` and `NOT BETWEEN`
* Pattern matching using `LIKE`
* Working with employee salary, department, city, and experience analysis

## Database Used

### Employees Table

| Column     | Description         |
| ---------- | ------------------- |
| emp_id     | Employee ID         |
| emp_name   | Employee Name       |
| department | Department Name     |
| salary     | Employee Salary     |
| city       | Employee City       |
