# SQL Practice Queries

This project contains basic SQL practice questions designed for beginners to improve their understanding of database concepts and query writing.

## Objective

The main objective of this practice set is to learn how to retrieve, filter, and manage data stored in relational databases using SQL commands.

## Tables Used

The practice questions are based on the following tables:

### Employee Table

Stores employee details such as:

* Employee ID
* Employee Name
* Age
* Salary
* Department ID
* Hire Date

### Department Table

Stores department-related information such as:

* Department ID
* Department Name

### Project Table

Stores project details assigned to employees and departments.

## Concepts Covered

This practice file covers important SQL topics including:

* Basic `SELECT` statements
* Filtering data using `WHERE`
* Pattern matching using `LIKE`
* Working with dates
* Aggregate functions
* Sorting records
* Grouping data
* Join operations
* Nested queries

## Learning Outcomes

After completing these exercises, users will be able to:

* Write simple and advanced SQL queries
* Retrieve specific records from tables
* Apply conditions and filters
* Understand relational database structure
* Perform data analysis using SQL

## Conclusion

These SQL practice questions help beginners build a strong foundation in database management and query writing. Regular practice improves problem-solving skills and prepares learners for academic projects, interviews, and real-world database applications.
